# Flavour Scripts

Reproducible scripts for the paper

**《合法符号类与味结构：夸克与轻子混合的域约束模型》(Legal Symbol Classes and Flavour Structure: A Domain-Constraint Model of Quark and Lepton Mixing)** — Chen Kaifa, October 2026.

These 19 scripts generated every numerical value quoted in the paper: the eight observables, the δ_CP convention correction (atan2), the π-conservation enumeration, the ρ fixed point, the two channel equations, the Blahut–Arimoto capacity audit, and the mass-ratio irreducibility search. All results were generated by the project's double-run convention: every script was run twice and the outputs were required to agree byte for byte.

## Requirements

- Python 3.9+
- NumPy
- SciPy (scipy.optimize)

## Usage

Run from this directory (the scripts import each other):

```bash
python phaseQ16.py
```

Each script writes its results to standard output and/or to `*_results*.txt` files in the current directory. Under the double-run convention, run each script twice and verify the outputs are byte-identical.

## Key conventions

- **δ_CP is always extracted with `atan2` (full circle)**. The `arcsin` branch would read the π branch as the 0 branch; the paper's convention correction is reproduced by `phaseQ15.py` and `phaseQ16.py`.
- **Channel capacity is always computed with the Blahut–Arimoto algorithm** (convergence provable; tolerance 1e-10/1e-12). `phaseQ31.py` performs the audit that superseded the earlier Nelder–Mead capacity values.
- Scripts whose results are negative (e.g. `phaseQ18.py`, part of `phaseQ22.py`, `phaseQ24.py`) are kept for the honest record; they document the candidates that were tested and excluded.

## 中文说明

本仓库是论文 **《合法符号类与味结构：夸克与轻子混合的域约束模型》（v5.0）**（陈开发，2026 年 10 月）的复现脚本集。

这 19 个脚本生成论文引用的全部数值：八项观测量、δ_CP 提取约定更正（atan2）、π 守恒枚举、ρ 不动点、两条信道方程、Blahut–Arimoto 容量审计与质量比不可约搜索。全部结果按项目的"双运行"约定生成：每个脚本运行两次，输出逐字节一致。

**运行环境**：Python 3.9+、NumPy、SciPy。

**用法**：在本目录下运行（脚本之间相互导入）：

```bash
python phaseQ16.py
```

每个脚本将结果输出至标准输出，并/或写入当前目录的 `*_results*.txt`。按双运行约定，每个脚本应运行两次并核对输出逐字节一致。

**脚本清单**：见上表（脚本名 | 计算内容 | 对应论文章节）。

**关键约定**：

- δ_CP 一律用 `atan2` 全圆提取（`arcsin` 会把 π 支误读为 0 支；约定更正由 `phaseQ15.py`/`phaseQ16.py` 复现）；
- 信道容量一律用 Blahut–Arimoto 算法（收敛可证，容差 1e-10/1e-12；`phaseQ31.py` 即对早期 Nelder-Mead 容量值予以更正的审计）；
- 负结果脚本（如 `phaseQ18.py`、`phaseQ22.py` 部分、`phaseQ24.py`）按"如实记录"原则保留，记录被检验并排除的候选。
